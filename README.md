# Project Setup

## Steps

### Step 1: Clone

`git clone https://github.com/sumant1512/msuite-server.git`

### Step 2: Install

`poetry install`

### Step 3: Run project

`poetry run uvicorn app.main:app --reload`

### Step 4: Healt check

`http://127.0.0.1:8000/`

### Step 5: Swagger

`http://127.0.0.1:8000/docs`
