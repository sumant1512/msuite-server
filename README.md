## Project Setup

## Clone project

## venv setup

`python -m venv venv`

## Activate venv using command

`venv\Scripts\activate`

## Install packages using

`pip install -r requirements.txt`

## Run project command

`python -m uvicorn app.main:app --reload`

### Setup for team

## Install

`poetry install`

## Run project

`poetry run uvicorn app.main:app --reload`
